# MorkvaCRM

A new-era CRM for small business, with automations and AI built in.

## Main points

- **Everything is a collection of cards** — a smart database, not a fixed sales pipeline.
- **Views over one data model** — kanban, table and dashboard are just different views of the same data.
- **Linking and automation** — reference cards from other collections and automate everything.
- **Extensible** — dynamic JS modules and a module marketplace; in the AI era you can build almost
  anything in hours with the module API.
- **Your data is portable JSON** — stored in the cloud (Cloud Firestore), so it can be shared across
  accounts and teams instead of being locked to one device.
- **Bring any AI tool** — the open JSON structure lets you analyse your data anywhere; export it at
  any time.
- **Web and mobile** — one modern, simple UI on both platforms.
- **Make it yours** — customize your workspace, scaffold it with AI, or start from templates.
